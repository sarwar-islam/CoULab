# আইনসহায় — বাংলাদেশ ডিজিটাল লিগ্যাল এইড পোর্টাল

Michigan Legal Help-এর কাঠামো অনুসরণ করে বাংলাদেশ-ভিত্তিক সম্পূর্ণ ওয়েবসাইট + ব্যাকএন্ড।
**Zero dependency** — শুধু Node.js (v18+) লাগবে।

## চালানো

```bash
npm start
# → http://localhost:3000
```

প্রথম চালানোতে `server/data/db.json` নিজে থেকে তৈরি হবে।

## ADLASB রুলবুক কভারেজ (২৩ ম্যান্ডেটরি আইটেম)

শেয়ার্ড-রেকর্ড আর্কিটেকচার (Golden Thread): প্রতিটি রেকর্ডে `audit[]` + ফিল্ড-বাই-ফিল্ড **provenance** (`applicant-confirmed` / `representative-reported` / `intermediary-translated` / `staff-entered` / `ai-inferred`), Application ID জমায় → Case ID শুধু DLAO গ্রহণের পরে (মানুষের সিদ্ধান্ত), রোল-ভিউতে একই রেকর্ডের সীমিত দৃশ্য (G9), সব অ্যাকশন একই audit ট্রেইলে।

- **Part A (৫ সিটিজেন):** A1 সেফ-কন্টাক্ট+প্রতিনিধি (ফরমেই অনিরাপদ নম্বর ব্লক) · A2 রিপ্রেজেন্টেটিভ স্কোপ · A3 স্পর্শকাতর+ট্র্যাকড রেফারেল (অ্যাক্সেস-ব্লক টেস্টেড) · A4 UDC অ্যাসিস্টেড+অফলাইন সিঙ্ক · A5 স্টেটাস heads-up (শুনানি/আইনজীবী/ব্যর্থ-কল)
- **Part B (৭ প্রোভাইডার):** B1 DLAO কিউ+ওভাররাইড · B2 মধ্যস্থতা (রিমোট/হাইব্রিড) · B3 ১৬৬৯৯ শেয়ার্ড রেকর্ড ভিউ · B4 UDC ফ্রি-সার্ভিস নোটিশ+অ্যাসিস্ট প্রোভেনেন্স · B5 আইনজীবী accept/decline+ওয়ার্কলিস্ট · B6 রেফারেল ack+ডেডলাইন · B7 সার্চ+রুটিন রিপোর্ট (কেস রেকর্ড থেকেই)
- **Part C (১১ টেক):** T1 আইনজীবী প্যাটার্ন-অ্যালার্ট+change-request টাস্ক · T2 জুরিসডিকশন এস্কালেশন · T3 লিংক-নট-মার্জ · T4 ফাজি ডুপ্লিকেট (কখনো অটো-রিজেক্ট নয়) · T5 কথোপকথনে বাংলা ইনটেক (AI সহায়ক) · T6 ডকুমেন্ট ব্রিফ+মিসিং ফ্ল্যাগ · T7 সেটেলমেন্ট ড্রাফট (হিউম্যান রিভিউ বাধ্যতামূলক) · T8 মাল্টি-এজেন্ট ট্রায়াজ+কনফ্লিক্ট · T9 অফলাইন সিঙ্ক (ইডেম্পোটেন্ট — ডুপ্লিকেট স্কিপ টেস্টেড) · T10 PWA (`/manifest.json` + আইকন) · T11 হ্যাশ-ভিত্তিক অ্যাসিনক্রোনাস ই-সিগ (ইন্টিগ্রিটি ভেরিফাই টেস্টেড)
- **রেসপন্সিবল-ডিজাইন:** যোগ্যতা/প্রত্যাখ্যান/প্রায়োরিটি/নিয়োগ/ফলাফল/ক্লোজার সবই অনুমোদিত মানুষের হাতে — AI শুধু অ্যাডভাইজরি; প্রতিটি মডিউল দৃশ্যমানভাবে ব্যর্থ হয় (রিট্রাই/হ্যান্ডঅফ/এস্কালেশন), নীরব ব্যর্থতা নেই

## স্ট্রাকচার

```
server.js          → HTTP সার্ভার + API + static + শেয়ার্ড-রেকর্ড কোর (audit/provenance)
server/db.js       → JSON ফাইল DB (server/data/db.json)
server/seed.js     → সব ডেটা: টপিক, আর্টিকেল, অফিস, নিউজ, গাইড, KB, APPLICATION_STAGES
public/index.html  → SPA শেল (+ PWA manifest/icon লিংক)
public/css/styles.css
public/js/app.js   → router + সব পেজ
public/js/console.js → প্রোভাইডার কনসোল (B1–B7, T1–T11, A1–A5, কভারেজ)
public/js/i18n.js  → বাংলা/English অভিধান
public/manifest.json, public/icon.svg → T10 PWA
```
